## tests/assets/

Tiny, repo-tracked assets for CI-safe integration tests.

- `sunflower.ppm`: placeholder “sunflower-like” image (ASCII PPM, no external deps)
- `other.ppm`: placeholder “non-sunflower” image (ASCII PPM, no external deps)

These files are not meant to be visually meaningful; they are stable, tiny fixtures to exercise
file plumbing and JSON output contracts without requiring ML dependencies in CI.
