# Manuscript publication exports (`reports/manuscript/`)

CPU-generated artifacts for **Word/LaTeX paste** after HSP metrics exist under [`reports/hsp/`](../hsp/README.md). Regenerated by `experiment.py manuscript-preflight` (full chain) or per-step subcommands.

## Layout

| Path | Schema / role |
|------|----------------|
| [`preflight_manifest.json`](preflight_manifest.json) | `manuscript_preflight_manifest.v1` — step status (`reviewer2_repro` → `figures_repro` → `tables_repro` → `docx_repro` → `aug_compare` → `backlog_narrative`) |
| [`tables/`](tables/) | `tables_manifest.json`, `headline_metrics.md`, `aug_smoke_top_n.md`, `zoo_core.md` (+ optional `.tex`) |
| [`docx/`](docx/README.md) | `catalog.json`, per-figure/table stubs for docx Figures 1–6 & Tables 1–3 |
| [`narrative_from_backlog.md`](narrative_from_backlog.md) | Repo draft narrative from [`backlog.md`](../../backlog.md) |
| [`backlog_narrative.json`](backlog_narrative.json) | Structured narrative export |

## Prerequisites

- **HSP:** `reports/hsp/dual_metric.json`, `gt_test.json`, `preds_test.json`, `threshold_val.json`, etc. (see [`hsp/README.md`](../hsp/README.md)).
- **Reviewer-2 (optional):** `reports/reviewer2_counting_metrics_computed.json`, `reports/hsp/best2_test_confusion.json` — `reviewer2_repro` step skips with warning if test exports missing.

## Commands

```bash
# Full preflight (config: manuscript_preflight in manuscript_repro_bundle.json)
mamba run -n harchoc python scripts/experiment.py manuscript-preflight
# or
mamba run -n harchoc python scripts/experiment.py repro --stage preflight

# CI-safe plan
PYTHONPATH=. HARCHOC_ALLOW_BASE_PYTHON=1 python scripts/experiment.py manuscript-preflight --dry-run

# Individual steps
mamba run -n harchoc python scripts/experiment.py tables-repro --out-dir reports/manuscript/tables
mamba run -n harchoc python scripts/experiment.py manuscript-docx-repro --out-dir reports/manuscript/docx
```

Implementation: `harchoc/manuscript_preflight.py`, `manuscript_tables.py`, `manuscript_docx_repro.py`, `aug_comparative.py`, `backlog_narrative.py`.

Docs: [`docs/EXPERIMENTS.md` § Publication preflight](../../docs/EXPERIMENTS.md#publication-preflight-before-word-paste).
