# HSP canonical reports (`reports/hsp/`)

**HSP** is an **internal repo shorthand** for manuscript counting eval artifacts (val tune → lock conf → test; full-frame `eval.py` @ 1280, not deploy SAHI). There is no official acronym expansion in the project docs—use **counting-first eval protocol** or **manuscript eval exports** in external prose.

This directory is the **single source of truth** for the **P0 credibility gate** on frozen splits (`875` train / `109` val / `109` test). Manuscript metrics, threshold locking, and dual-metric tables should cite paths here—not stale exports at the repo root.

## P0 protocol (frozen)

| Setting | Value |
|---------|--------|
| Detection weights | `models/best2.pt` |
| `imgsz` | **1280** |
| Export `conf` | **0.001** |
| Export NMS IoU | **0.3** |
| Export `max_det` | **3000** |
| Threshold workflow | Tune on **val** → lock conf → apply on **test** (no test leakage) |

Typical chain: `eval.py` exports → `threshold_sweep.py` (val) → `threshold_sweep.py --locked-conf-from` (test) → `error_analysis.py` → `experiment.py dual-metric`. Spec: `configs/experiments/eval_hsp_baseline.json`.

## Canonical P0 artifacts

| Artifact | Role |
|----------|------|
| `dual_metric.json` | Merged mAP + counting + operating point (`dual_metric_report.v1`) |
| `threshold_val.json` | Val conf sweep; **selected** operating conf |
| `threshold_test_locked.json` | Test sweep with **locked** conf from val |
| `threshold_val.csv` | Human-readable sweep table (optional) |
| `gt_val.json`, `gt_test.json` | Ground-truth exports for sweeps |
| `preds_val.json`, `preds_test.json` | Low-conf prediction exports |
| `error_val.json`, `error_test.json` | Per-image counting errors at locked conf |
| `split_drift_p0.json` | P0 split drift + KS acceptance (`split_drift_report.v1`) |
| `s14_maxdet_truncation.json` | S14 negative control: count MAE @ `max_det` 300 vs 3000 (`s14_maxdet_control.v1`) |
| `baseline_models.md`, `baseline_models_manifest.json` | Frozen weight roles and checksums |
| `rtdetr_smoke_15ep.json` | RT-DETR 15-ep smoke probe / train status |

**Supporting eval inputs (same protocol):** `eval_val.json`, `eval_test.json`, `eval_data.yaml`, `eval_val_abs_paths.txt`. S14 arm: `eval_test_maxdet300.json`, `preds_test_maxdet300.json`, `threshold_test_maxdet300_locked.json`.

**Optional (regenerated by `error_analysis.py --report`):** `error_val_report.json`, `error_test_report.json` — taxonomy summaries; prior copies live under [`reports/_archive/hsp/`](../_archive/hsp/).

## Regenerating P0 (reference)

```bash
# From repo root, mamba env harchoc
mamba run -n harchoc python scripts/split_drift.py --with-ks --out reports/hsp/split_drift_p0.json
mamba run -n harchoc python scripts/experiment.py eval --config configs/experiments/eval_hsp_baseline.json
# … threshold_sweep, error_analysis, dual-metric per docs/RESEARCH_AND_OPS.md
```

RT-DETR smoke: `mamba run -n harchoc python scripts/rtdetr_smoke.py` [`--run-train`] → `rtdetr_smoke_15ep.json`.
