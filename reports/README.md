# Reports

Machine-readable experiment outputs (JSON/CSV) and publication markdown for the manuscript counting pipeline (**HSP** = internal shorthand for [`hsp/`](hsp/) JSON; not a published acronym). Val→locked-conf→test exports live under `hsp/`; deploy/SAHI metrics are separate. Paths here are citation sources for manuscript numbers.

- **Do not commit** most run outputs (gitignored); see **Tracking policy** below.
- **Regenerate:** [`docs/EXPERIMENTS.md`](../docs/EXPERIMENTS.md).
- **Agent status:** [`docs/manuscript/status.md`](../docs/manuscript/status.md).

## Tracking policy (git)

| Path pattern | Git | Notes |
|--------------|-----|--------|
| `reports/hsp/*.json`, `reports/hsp/*.csv` | **Local only** (under `reports/**/*`) | Canonical metrics on disk; cite paths in manuscript |
| `reports/manuscript/**/*.md` | **Tracked** | Prose, rebuttal, lit_audit, `reviewer2/` index |
| `reports/manuscript/**/*.json` | **Ignored** | `preflight_manifest.json`, `tables_manifest.json` — regenerate locally |
| `reports/manuscript/narrative_from_backlog.md` | **Ignored** | Regenerated by `experiment.py backlog-narrative` / preflight |
| `reports/manuscript/now_todos_smoke.json` | **Ignored** | Harness output from `experiment.py now-todos-smoke` |
| `reports/reviewer2.md` | **Tracked** | Verbatim reviewer text |
| `reports/_llm/` | **Tracked** (if present) | LLM audit index |
| `reports/aug_smoke/`, `reports/gpu_queue/` | **Ignored** | Queue logs and smoke summaries |

`.gitignore` uses `reports/manuscript/*` plus negations for `**/*.md` and `lit_audit/` / `reviewer2/`. JSON under `manuscript/` stays ignored even in subfolders.

## Layers

| Layer | Path | Audience |
|-------|------|----------|
| **Human manuscript** | [`manuscript/`](manuscript/) | Abstract, rebuttal, methods/results prose for Word paste |
| **HSP metrics** | [`hsp/`](hsp/) | Canonical JSON + [`p0_summary.md`](hsp/p0_summary.md) headline card |
| **LLM validation** | [`_llm/`](_llm/) | Reproduce commands, audits, paste-check index |
| **Docx tables/figures** | [`manuscript/docx/`](manuscript/docx/) | Generated journal-style exports |

## Regeneration

| Goal | Command |
|------|---------|
| HSP + dual-metric | `experiment.py repro` |
| Reviewer validation JSON | `experiment.py reviewer2-repro` |
| Publication preflight | `experiment.py manuscript-preflight` |
| Docx-aligned tables/figures | `experiment.py manuscript-docx-repro` |
